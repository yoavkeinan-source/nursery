# קטלוג המשתלה – גרסה עצמאית (GitHub Pages + Firebase)

אפליקציית אינטרנט (PWA) לקטלוג צמחים, מחירון ורשימות ללקוחות.
האתר יושב ב-GitHub Pages; הכניסה, הנתונים והתמונות ב-Firebase (תוכנית Spark החינמית).

**הוראות התקנה בעברית:** פתחו את `הוראות-התקנה.html` בדפדפן.

## הקבצים
- `index.html` – האפליקציה
- `config.js` – הגדרות פרויקט ה-Firebase (ממלאים פעם אחת)
- `fb-adapter.js` – כניסה, נתונים ותמונות מול Firebase
- `firestore.rules` – כללי אבטחה: מנהלים רואים ועורכים הכל; עובדים רואים רק את הקטלוג
- `sw.js`, `manifest.webmanifest`, `icons/` – התקנה בטלפון ועבודה בלי קליטה
- `vendor/` – ספריות Firebase, PDF ואקסל, שמורות מקומית
