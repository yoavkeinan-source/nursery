הוראות התקנה

GitHub Pages לאתר, Firebase לנתונים, לתמונות ולכניסה. הכל בחינם ובלי כרטיס אשראי. בערך 20 דקות, פעם אחת. שמות הכפתורים באנגלית, ולפעמים משתנים מעט.

  1. פרויקט חדש ב־Firebase

    • נכנסים ל־console.firebase.google.com ← Create a project. שם, למשל nursery-catalog. אפשר לכבות את Google Analytics.
    • נשארים בתוכנית Spark (החינמית). לא צריך לשדרג.

  2. הפעלת כניסה עם מייל וסיסמה

    • Build ← Authentication ← Get started ← Email/Password ← להפעיל (Enable) ← Save.
    • לשונית Users ← Add user: האימייל שלך וסיסמה. זה המשתמש שלך.
    • כדי שזרים לא יוכלו להירשם: Settings ← User actions ← לבטל את Enable create (sign-up). אם האפשרות לא מופיעה, זה לא נורא: מי שנרשם בעצמו רואה רק את הקטלוג, בלי מחירים ולקוחות.

  3. מסד הנתונים וכללי האבטחה

    • Build ← Firestore Database ← Create database ← מיקום באירופה (למשל eur3) ← Production mode.
    • לשונית Rules: מוחקים את מה שכתוב, מדביקים את כל התוכן של הקובץ firestore.rules מהתיקייה ← Publish.
    • הגדרתך כמנהל: לשונית Data ← Start collection ← Collection ID: admins ← Document ID: האימייל שלך באותיות קטנות ← אפשר להוסיף שדה כלשהו (למשל role = owner) ← Save.

  4. חיבור האפליקציה לפרויקט

    • גלגל השיניים ← Project settings ← למטה Your apps ← הסמל </> (Web) ← שם כלשהו ← Register app. לא לסמן Firebase Hosting.
    • מופיע קוד עם firebaseConfig. מעתיקים את הערכים apiKey, authDomain, projectId, appId.
    • פותחים את config.js בפנקס רשימות, מדביקים כל ערך במקומו בין הגרשיים, ושומרים.
    • אם נוח יותר, שלח לי את הקטע הזה ואחזיר לך תיקייה מוכנה. ההגדרות האלה נועדו להיות גלויות באתר. האבטחה נעשית בכללים מהשלב הקודם.

  5. העלאה ל־GitHub Pages

    • ב־GitHub: New repository ← שם, למשל nursery ← Public ← Create.
    • uploading an existing file (או Add file ← Upload files) ← גוררים את כל מה שבתוך התיקייה plant-app, כולל התיקיות vendor ו־icons ← Commit changes.
    • Settings ← Pages ← Source: Deploy from a branch ← Branch: main / (root) ← Save.
    • אחרי דקה-שתיים מופיעה הכתובת, למשל https://שם-המשתמש.github.io/nursery/.
    • חוזרים ל־Firebase: Authentication ← Settings ← Authorized domains ← Add domain ← שם-המשתמש.github.io.

  6. התקנה בטלפון

    • פותחים את הכתובת ונכנסים עם המייל והסיסמה. מתחברים פעם אחת, וזה נשמר.
    • אנדרואיד (Chrome): תפריט ⋮ ← התקנת אפליקציה או הוספה למסך הבית.
    • אייפון (Safari): כפתור השיתוף ← הוספה למסך הבית.

  7. העברת הנתונים מהגרסה ב־Claude

    • בגרסה ב־Claude: הגדרות ← גיבוי מלא ← לסמן "כולל תמונות" ← הורדת גיבוי.
    • באפליקציה החדשה: הגדרות ← שחזור מקובץ גיבוי ← בוחרים את הקובץ.

  8. עובדים

    • לכל עובד: Authentication ← Users ← Add user.
    • מי שלא נמצא באוסף admins רואה רק את קטלוג הצמחים, בלי מחירים, ספקים ולקוחות, ולא יכול לשנות. זה נאכף בכללי Firebase, לא רק במסך.
    • למנהל נוסף: מוסיפים עוד מסמך לאוסף admins, עם האימייל שלו כ־Document ID.

חשוב לדעת

  • לא נרדם: גם אם לא נכנסים חודשים, האפליקציה עובדת מיד.
  • בלי קליטה: רואים את הנתונים ואת התמונות שכבר נצפו. שינויים נשמרים במכשיר ונשלחים לבד כשהחיבור חוזר.
  • תמונות: נשמרות בתוך מסד הנתונים, ומוקטנות אוטומטית לגודל שמתאים לטלפון ולמצגת. המקום החינמי מספיק לכמה אלפי תמונות.
  • גיבוי: פעם בחודש, הגדרות ← הורדת גיבוי.
  • עדכונים: כשאשלח גרסה חדשה, מעלים את הקבצים החדשים לאותו מאגר ב־GitHub (Add file ← Upload files), ומחליפים את הקיימים. לא להחליף את config.js שלך.
  • בגרסה הזו אין חיפוש חכם, זיהוי מתמונה, מילוי אוטומטי והצעת גינה, כי אלה דורשים את Claude. כל השאר עובד.
